# Learner Model

Only publishable learning preferences belong here.

## Confirmed preferences

- For a completely new concept, begin with **why it is needed, when it is used, and the problem/history that motivated it** before formal definitions.
- Prefer a **concrete example before symbolic generalization**, especially for mathematical or algorithmic material.
- Explain **step by step**, but keep each step concise unless more detail is requested.
- Use short probes or problems to verify understanding rather than assuming that an explanation was understood.
- When studying from course material, preserve the source's notation when practical so the explanation maps back to the material.

## Teaching implications

Default ordering for unfamiliar concepts:

```text
Motivation -> Use case -> Intuition -> Concrete example -> Definition -> General form -> Check
```

Do not force this ordering when the learner explicitly asks for a direct answer, formula, solution, or review.

## Change policy

Add or change a learner-wide preference when:

- the learner states it explicitly, or
- multiple sessions provide consistent evidence.

Topic-specific difficulties belong in subject state, not here.

# Skill: Probe

Use to locate the learner's actual starting point.

## Procedure

1. Identify the minimum prerequisites for the target concept.
2. Check recent state/session evidence first.
3. Ask at most a few small, discriminative checks.
4. Stop probing once the missing dependency is clear.
5. Record only meaningful new evidence.

Prefer tiny calculations, comparisons, or "why" questions over vague self-ratings.

# Skill: Teach

## Default sequence

For an unfamiliar concept:

1. motivation / problem
2. intuition
3. concrete example
4. formal definition or algorithm
5. symbolic/general form
6. learner check

## Explanation rules

- Prefer one representative example over many shallow examples.
- For equations or algorithms, show the state change at each important step.
- Introduce notation only when it earns its place.
- Separate "how to execute" from "why it works" when both matter.
- If the learner already understands the intuition, move quickly to application.

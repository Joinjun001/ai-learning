# Subject Skill: Cryptography

Apply these rules in addition to common skills.

## Orientation

Before an algorithm, identify the security goal and threat model when relevant:

- confidentiality
- integrity
- authenticity
- non-repudiation
- key establishment

## Mathematics

- Repair modular arithmetic prerequisites just in time.
- Prefer concrete integers before variables for gcd, extended gcd, modular inverse, exponentiation, and congruences.
- Distinguish a mathematically valid computation from a cryptographically secure construction.

## Concept boundaries

Explicitly distinguish when relevant:

- encoding vs encryption
- hashing vs encryption
- MAC vs digital signature
- encryption vs key exchange
- correctness vs security assumption

## Course alignment

When material is supplied, preserve its notation and terminology unless it is incorrect or actively confusing. Explain alternate notation only after the course notation is understood.

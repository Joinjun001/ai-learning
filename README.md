# Personal Learning Lab

**Personal Learning Lab**은 개인 맞춤형 **1:1 AI 학습 시스템을 구축하고, 1년 동안 나 자신을 학습 데이터로 삼아 학습 과정과 시스템의 변화를 관찰·누적하기 위한 프로젝트**다.

단순히 AI에게 질문하고 답을 받는 것을 넘어, 학습자의 현재 이해 수준과 학습 성향을 지속적으로 기록하고 그 데이터를 바탕으로 **설명 방식, 학습 경로, 문제 난이도, Teaching Skill을 장기적으로 개선하는 것**을 목표로 한다.

이 프로젝트는 Eero Alvar의 [How I Use AI to Learn Things](https://www.youtube.com/watch?v=kzcI5F4tGiU)에서 제시한 1:1 AI 학습 방식에서 아이디어를 얻었다.

## 문제의식

기존 학습은 크게 두 방향에서 비효율이 발생한다.

### 1. 하나의 교육 방식이 많은 학습자를 대상으로 한다

강의, 교재, 인터넷 강좌는 일반적으로 많은 학습자를 대상으로 만들어진다.

하지만 학습자마다 이미 알고 있는 내용, 부족한 선수지식, 이해하기 쉬운 설명 방식이 다르기 때문에 **모두에게 동일한 학습 순서와 설명이 최적일 수는 없다.**

결과적으로 이미 아는 내용을 반복하거나, 아직 준비되지 않은 내용을 먼저 접하는 문제가 생긴다.

### 2. 한 학습자가 너무 많은 자료를 직접 조합해야 한다

반대로 학습자는 강의, 교재, 블로그, 영상, 검색 결과, AI 등 여러 출처를 오가며 공부한다.

이 과정에서 실제 학습 이외에도 다음과 같은 작업에 인지 자원이 사용된다.

- 어떤 자료를 봐야 하는지 찾기
- 서로 다른 설명 방식과 표기법에 적응하기
- 어떤 순서로 공부해야 하는지 판단하기
- 정보가 정확한지 검증하기
- 이전에 무엇을 이해했고 어디서 막혔는지 다시 파악하기

즉, **공부 자체보다 공부를 관리하는 데 정신적 자원이 소모되는 문제**가 있다.

## 핵심 아이디어

Personal Learning Lab은 AI를 여러 자료를 대체하는 하나의 지식 원천으로 사용하는 것이 아니라, **여러 정보와 학습 도구를 연결하는 하나의 개인화된 학습 인터페이스**로 사용한다.

```text
여러 자료 / 관점 / 문제
          ↓
     AI Learning System
          ↓
현재 학습자의 상태에 맞는
하나의 학습 경로와 설명
```

AI가 자료 탐색, 학습 순서 구성, 상태 기록 등의 부가 작업을 담당하고, 학습자는 가능한 한 **이해하고 생각하고 문제를 푸는 일에 집중하도록 만드는 것**이 기본 방향이다.

## 학습 흐름

기본 학습 과정은 다음과 같다.

```text
Probe
현재 이해 수준과 선수지식 확인
        ↓
Plan
현재 상태에서 목표까지의 학습 경로 구성
        ↓
Teach
한 단계씩 설명하고 필요한 예제 제공
        ↓
Quiz
실제로 이해했는지 확인
        ↓
Update
학습 상태와 피드백 기록
        ↓
다음 학습에 반영
```

### Probe

무엇을 모르는지 처음부터 가정하지 않고, 질문과 문제를 통해 현재 지식의 경계를 찾는다.

### Plan

이미 알고 있는 내용은 건너뛰고 부족한 선수지식부터 연결하여 **현재 학습자에게 필요한 경로**를 만든다.

### Teach

정해진 설명을 그대로 출력하는 대신 학습자의 반응에 따라 설명 수준과 방식을 조절한다.

현재 기본 원칙은 새로운 개념을 배울 때 다음 순서를 우선하는 것이다.

```text
왜 필요한가
→ 어디에 사용하는가
→ 직관
→ 구체적인 예제
→ 정의와 일반화
→ 이해 확인
```

### Quiz & Update

설명을 들었다는 사실을 이해했다는 증거로 사용하지 않는다.

짧은 문제나 설명을 통해 이해 여부를 확인하고, 그 결과를 다음 학습의 입력 데이터로 사용한다.

## 이 프로젝트의 목적

이 프로젝트의 핵심은 완성된 AI Tutor를 한 번 만드는 것이 아니다.

**한 명의 학습자를 장기간 관찰했을 때 학습 시스템이 얼마나 개인화될 수 있는지 직접 실험하는 것**이 목적이다.

약 1년 동안 실제 대학 수업과 개인 학습에 시스템을 사용하면서 다음 데이터를 누적한다.

- 어떤 개념을 이해하고 있는가
- 어떤 선수지식에서 반복적으로 막히는가
- 어떤 설명 방식에서 이해도가 높아지는가
- 어떤 종류의 예제와 문제가 효과적인가
- AI가 판단한 이해 수준과 실제 문제 해결 능력이 얼마나 일치하는가
- 학습 경험이 쌓이면서 필요한 Probe가 얼마나 줄어드는가
- Teaching Skill이 어떻게 수정되고 발전하는가

이를 통해 시간이 지날수록 AI가 단순히 "질문에 답하는 모델"이 아니라 **학습자의 과거 학습 기록을 바탕으로 다음 학습을 설계하는 개인 학습 시스템**으로 발전할 수 있는지를 관찰한다.

## 장기적으로 관찰하고 싶은 것

```text
초기
AI가 학습자를 거의 모름
↓
학습 세션 누적
↓
오개념 / 이해도 / 선호 설명 방식 기록
↓
Learner Model + Teaching Skill 개선
↓
더 적은 탐색으로 현재 수준 파악
↓
더 정확한 개인 학습 경로 제공
```

1년 뒤에는 단순한 대화 기록이 아니라, **한 사람의 학습 방식이 어떻게 모델링되었고 그 모델이 실제 학습에 어떤 영향을 주었는지 확인할 수 있는 데이터**를 남기는 것을 목표로 한다.

## 프로젝트 구조

```text
personal-learning-lab/
├── SYSTEM.md                  # 전체 시스템 운영 원칙
├── BOOTSTRAP.md               # 새로운 학습 세션 시작 절차
├── learner/
│   └── LEARNER.md             # 과목과 무관한 공통 학습 성향
├── skills/
│   ├── common/                # Probe, Plan, Teach, Quiz 등 공통 Skill
│   └── subjects/              # 과목별 Teaching Skill
├── subjects/
│   └── <subject>/
│       ├── STATE.json         # 현재 이해도와 다음 학습 상태
│       └── MAP.md             # 지식 구조 및 선수 관계
└── sessions/
    └── <subject>/             # 학습 세션별 관찰 기록
```

## 기록 원칙

Git에는 대화 전체를 그대로 저장하기보다 **다음 학습에 실제로 필요한 변화만 기록한다.**

```text
학습
→ 이해도 / 오개념 발견
→ 세션 요약
→ Subject State 갱신
→ 필요한 경우 Learner / Skill 수정
→ Git commit
```

Git history 자체가 시간이 지나면서 **학습자 모델과 1:1 학습 시스템이 어떻게 변화했는지 보여주는 실험 기록**이 되도록 한다.
